# 青禾班主任工作台

面向普通初中班主任的轻量工作台。包含工作台首页、成绩 CSV 导入与分析、座次调整、学生名册、值日编辑和待办，并使用浏览器本地存储保存操作。

线上地址：<https://ricardomfu.github.io/qinghe-classroom-studio/>

## 本机运行

```bash
npm install
npm run dev
```

打开终端显示的本机地址；同一局域网的其他设备可打开 `http://本机局域网IP:5173`。

生产构建：

```bash
npm run build
npm run preview
```

`preview` 默认监听 `0.0.0.0`。如需常驻运行，建议后续使用固定域名 + HTTPS 部署；仅局域网 IP 无法跨不同网络稳定访问。

## 已落地功能

- CSV 成绩导入、校验、统计、学科筛选和排名。
- 新增学生并同步到名册与座次表。
- 两次点击交换座位，避免拖拽误操作。
- 值日安排编辑、待办新增/完成与刷新持久化。
- 桌面、平板、手机响应式，PWA 外壳和 GitHub Pages 自动部署。

## 测试

```bash
npm test
npm run build
```

GitHub Actions 会在每次推送后重复运行测试和构建，通过后才发布。

## 数据边界

当前线上版仅包含演示数据，数据保存在使用者自己的浏览器中，不会上传到服务器。正式接入真实姓名、成绩、联系方式或多人协作前，应升级为带账号登录、权限分级、加密数据库、备份和访问日志的私有部署。
